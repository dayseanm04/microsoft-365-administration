## 1. The URL

`cuny907.sharepoint.com/_layouts/15/sharepoint.aspx/discover`

| Part | What it means |
|---|---|
| **`cuny907`** | The school's **tenant name**. Every company has its own. At a different company it'll be **`companyname.sharepoint.com`** |
| **`sharepoint.com`** | This is **SharePoint Online**, the cloud version |
| **`/_layouts/15/sharepoint.aspx`** | The SharePoint **start page**. It's your personal starting point, not a site |
| **`/discover`**, **`/publish`**, **`/build`**, **`/onedrive`** | Changes depending on which tab on the left you click |

The start page isn't a site. It's a dashboard that points you to sites, files and tools. Real sites have URLs like **`cuny907.sharepoint.com/sites/SiteName`**.

## 2. Top bar (on every page)

<img width="1071" height="410" alt="4" src="https://github.com/user-attachments/assets/d6e3337f-fd8f-4f6c-bdd7-7df6627099c4" />

| Item | What it does |
|---|---|
| **App launcher** (9 dots, top left) | Switches between Microsoft 365 apps: Outlook, Teams, OneDrive, Word and others. Admins also see an **Admin** tile here |
| **SharePoint** | Click it to get back to the start page from anywhere |
| **Search in SharePoint** | Searches sites, files, pages and people. You only see results you have permission to see |
| **Gear (Settings)** | Personal settings for your account. Inside a site, this gear is where **Site contents**, **Site permissions** and **Site information** are, which is where most admin troubleshooting starts |

## 3. Left rail: the four main areas

<img width="796" height="508" alt="5" src="https://github.com/user-attachments/assets/22d5bdcc-fd29-49d8-8537-bf0dc77a3d44" />

| Option | What it shows |
|---|---|
| **Overview** | Recent sites and updates from coworkers |
| **Sites** | Sites you've visited, followed, or been suggested |
| **News** | News posts from sites you follow |
| **People** | Coworkers or classmates and what they're working on |
| **Favorites** | Sites and files you've starred |
| **Recent items** | Files and pages you opened recently |
**Use it when:** You're looking for a site or file and don't remember where it is.

### Publish: create pages and news posts

URL ends in `/publish`

<img width="829" height="659" alt="6" src="https://github.com/user-attachments/assets/6a64eceb-abae-41bb-a5c8-1179755f5a12" />

| Item | What it does |
|---|---|
| **Create** | Make a new page or news post |
| **Pages** | Pages you made |
| **News posts** | News posts you made |
| **Analytics** | How many people viewed your pages |

**Use it when:** You need to make content people will read, like an announcement or how-to page. This is more of a user/content task than admin, but you should know where it is.

### Build: create sites, lists and libraries

URL ends in `/build`

<img width="1354" height="886" alt="7" src="https://github.com/user-attachments/assets/1f76e204-7687-43d6-ac38-c655f10a1c04" />

| Option | What it does |
|---|---|
| **Site** | Create a new site. This is where I made my practice site. If it's blocked, the organization has turned off self-service site creation |
| **List** | Create a list, like a table for tracking tasks or equipment |
| **Document library** | Create a place to store and manage files, with versioning and permissions |
| **Agent** | A Copilot AI assistant that answers questions using SharePoint content. It may need a Copilot license |
| **Owned by you** | Everything you own: Sites, Knowledge bases, Lists, Document libraries, Agents. Use the filters at the top |

**Use it when:** You need to create something new. **Owned by you** is a fast way to find everything you're the owner of.

### OneDrive: your personal files

URL ends in `/onedrive`

<img width="1079" height="746" alt="8" src="https://github.com/user-attachments/assets/3be7234c-3dee-4c2e-8111-012c4e8755a9" />

| Option | What it shows |
|---|---|
| **My files** | Your own personal storage. Only you can see it unless you share something |
| **Libraries** | SharePoint document libraries you've used, so you can get to site files from here |
| **Recycle bin** | Files you deleted from **your OneDrive**. This isn't the same as a site's recycle bin |
