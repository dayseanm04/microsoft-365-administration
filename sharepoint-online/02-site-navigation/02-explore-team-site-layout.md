# 02 - Explore the Team Site Layout

## Goal

Learn what each part of a team site is, and where to go for common admin tasks.

## 1. Top bar

<img width="924" height="200" alt="5" src="https://github.com/user-attachments/assets/6fcd1e15-58a5-4029-a43d-f32e67ad52cc" />

| Item | What it does |
|---|---|
| **Search this site** | Searches only this site. On the SharePoint start page, search covers all of SharePoint |
| **Megaphone icon** | Next steps to improve your site |
| **Gear (Settings)** | The most important button for admin work (see below) |
| **Your name** | Shows which account you're signed in with |

### Gear menu

<img width="549" height="751" alt="6" src="https://github.com/user-attachments/assets/c635ffb4-dad0-49b2-a405-da8643deaef2" />

| Item | What it does |
|---|---|
| **Site contents** | Everything on the site: libraries, lists, pages |
| **Site information** | Change the site name, description and logo |
| **Site permissions** | See and change who has access |
| **Site usage** | How much the site is used |
| **Apply a site template** | Switch to a different template |
| **Change the look** | Theme, header and navigation style |
| **Add a page / Add an app** | Create a new page, or add a list or library |

## 2. Site header

<img width="1089" height="222" alt="7" src="https://github.com/user-attachments/assets/19c205ba-60a8-438c-88c7-657a56e5fe1c" />

| Item | What it means |
|---|---|
| **SP logo + site name** | The site's icon and display name. Change them in Gear → **Site information** |
| **Private group** | Only members can get in. This came from the privacy setting when I made the site |
| **Added to favorites** | Starred, so it shows up under Discover → **Favorites** |
| **1 member** | Click it to see and add **group members**. Right now it's just me. Adding someone here gives them access to the whole site, plus the group email, calendar and notebook |

## 3. Left navigation (site menu)

<img width="624" height="436" alt="8" src="https://github.com/user-attachments/assets/aa5deeca-c001-4203-a4d6-2605609d4e8b" />

| Link | Where it goes |
|---|---|
| **Home** | The site home page (what you're looking at) |
| **Conversations** | The group's shared email inbox in Outlook |
| **Documents** | The main **document library**, where team files are stored |
| **Notebook** | The group's shared OneNote notebook |
| **Pages** | All pages on the site, including the home page and news posts |
| **Site contents** | **Everything on the site**: libraries, lists, pages and the recycle bin. You'll use this a lot |
| **Recycle bin** | Files deleted from **this site**. The second-stage recycle bin link is at the bottom of this page |
| **Edit navigation** | Add, remove or rename links in this menu |
