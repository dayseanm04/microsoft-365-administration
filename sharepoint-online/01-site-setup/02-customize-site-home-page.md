# 02 - Customize the Site Home Page

## Goal

Clean up the default home page on my team site by removing sections I don't need, changing the layout, and publishing the changes.

## Environment
- Microsoft 365 through my school account
- Site: SharePoint Practice Lab (team site from [**01 - Create a Team Site**](01-create-team-site.md))

---

## Steps

### 1. Open the site

From the SharePoint start page, go to **Discover → Overview**. My site shows up under **Recent sites**. Click it.

<img width="1096" height="682" alt="1" src="https://github.com/user-attachments/assets/eaee35ee-70a2-4390-bac4-c22869ae16a8" />

### 2. Look at the default home page

A new team site home page comes with these sections:
- **News**
- **Activity**
- **Quick links**
- **Documents**

<img width="1405" height="1032" alt="2" src="https://github.com/user-attachments/assets/cf30462e-fd55-4f7c-95a4-1f0606e7671f" />

### 3. Go into edit mode

Click **Edit** (top right). The page switches to edit mode and the **Toolbox** opens on the right with web parts you can add (Text, Image, Quick links, News, People, Hero, etc.).

<img width="679" height="375" alt="3" src="https://github.com/user-attachments/assets/ae3b3381-3a70-45ef-8809-cf88ef459f3c" />

### 4. Look at a web part's settings

Click the **News** section, then click **Edit properties** (the slider icon in the small toolbar).
