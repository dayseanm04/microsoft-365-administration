# 02 - Customize the Site Home Page

## Goal

Clean up the default home page on my team site by removing sections I don't need, changing the layout, and publishing the changes.

## Environment
- Microsoft 365 through my school account
- Site: SharePoint Practice Lab (team site from [**01 - Create a Team Site**](01-create-team-site.md))

---

## Steps

### 1. Open the site

From the SharePoint start page, go to **Discover → Overview**. My site shows up under **Recent sites**. Click it.

<img width="1096" height="682" alt="1" src="https://github.com/user-attachments/assets/eaee35ee-70a2-4390-bac4-c22869ae16a8" />

### 2. Look at the default home page

A new team site home page comes with these sections:
- **News**
- **Activity**
- **Quick links**
- **Documents**

<img width="1405" height="1032" alt="2" src="https://github.com/user-attachments/assets/cf30462e-fd55-4f7c-95a4-1f0606e7671f" />

### 3. Go into edit mode

Click **Edit** (top right). The page switches to edit mode and the **Toolbox** opens on the right with web parts you can add (Text, Image, Quick links, News, People, Hero, etc.).

<img width="679" height="375" alt="3" src="https://github.com/user-attachments/assets/ae3b3381-3a70-45ef-8809-cf88ef459f3c" />

### 4. Look at a web part's settings

Click the **News** section, then click **Edit properties** (the slider icon in the small toolbar).

<img width="672" height="219" alt="4" src="https://github.com/user-attachments/assets/62eebf85-3676-446d-ac9f-b947934b3d6e" />

The settings panel opens on the right. Some of what you can change:

<img width="334" height="848" alt="5" src="https://github.com/user-attachments/assets/53125dda-a678-450c-8e86-be5af6ac1275" />

<img width="358" height="853" alt="5" src="https://github.com/user-attachments/assets/48fa8cfb-4ab6-455a-a252-a31d7e87a676" />

| Setting | Options |
|---|---|
| News source | This site, Select sites, Recommended for current user |
| Layout | Top story, List, Side-by-side, Hub News, Carousel, Tiles |
| Show / hide | Title, commands, author, published date, number of views |
| Filter | Show only news whose title includes certain words |
| Audience targeting | Show news only to certain groups |
| Organize | Set the order news posts appear in |

### 5. Delete the News web part

Click the **News** section, click the **trash can** (Delete web part), then confirm **Delete**.

> **Note:** I removed the News section to show how deleting a web part works. I add it back later in [**04 - Create a news page**](04-create-news-page.md), since that's where my news posts show up.
