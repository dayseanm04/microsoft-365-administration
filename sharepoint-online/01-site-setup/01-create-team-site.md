# 01 - Create a SharePoint Team Site

## Goal
Create a private team site to use as my practice lab for learning SharePoint administration: permissions, sharing, libraries, lists and recovery.

## Environment
- Microsoft 365 through my school account
- Since it's a school tenant and not an admin account, I don't have access to every feature (no SharePoint admin center)

---

## Steps

### 1. Sign in to Microsoft 365

Go to [https://m365.cloud.microsoft](https://m365.cloud.microsoft) and sign in.

<img width="933" height="659" alt="1" src="https://github.com/user-attachments/assets/cd64d7d4-acee-4657-986f-0c6afe1b9a57" />

### 2. Open SharePoint

Click the app launcher (the 9 dots, top left) and select **SharePoint**.

<img width="917" height="557" alt="2" src="https://github.com/user-attachments/assets/4705d4a8-994b-4468-894f-4ec067e0f3ce" />

### 3. Go to Build

The SharePoint start page has four tabs on the left: **Discover**, **Publish**, **Build** and **OneDrive**. 

<img width="1025" height="612" alt="3" src="https://github.com/user-attachments/assets/776f7a27-75c7-4957-82f6-ad2b285a7dd3" />

Click **Build**.

<img width="1303" height="855" alt="4" src="https://github.com/user-attachments/assets/77648634-41b3-4da1-9c19-74593abaa8e7" />

### 4. Choose Site

Under **Start building**, you can create a Site, List, Document library or Agent. Click **Site**.
