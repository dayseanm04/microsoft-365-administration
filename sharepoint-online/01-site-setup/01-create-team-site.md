# 01 - Create a SharePoint Team Site

## Goal
Create a private team site to use as my practice lab for learning SharePoint administration: permissions, sharing, libraries, lists and recovery.

## Environment
- Microsoft 365 through my school account
- Since it's a school tenant and not an admin account, I don't have access to every feature (no SharePoint admin center)

---

## Steps

### 1. Sign in to Microsoft 365

Go to [https://m365.cloud.microsoft](https://m365.cloud.microsoft) and sign in.

<img width="933" height="659" alt="1" src="https://github.com/user-attachments/assets/cd64d7d4-acee-4657-986f-0c6afe1b9a57" />

### 2. Open SharePoint

Click the app launcher (the 9 dots, top left) and select **SharePoint**.

<img width="917" height="557" alt="2" src="https://github.com/user-attachments/assets/4705d4a8-994b-4468-894f-4ec067e0f3ce" />

### 3. Go to Build

The SharePoint start page has four tabs on the left: **Discover**, **Publish**, **Build** and **OneDrive**. 

<img width="1025" height="612" alt="3" src="https://github.com/user-attachments/assets/776f7a27-75c7-4957-82f6-ad2b285a7dd3" />

Click **Build**.

<img width="1303" height="855" alt="4" src="https://github.com/user-attachments/assets/77648634-41b3-4da1-9c19-74593abaa8e7" />

### 4. Choose Site

Under **Start building**, you can create a Site, List, Document library or Agent. Click **Site**.

<img width="1181" height="795" alt="5" src="https://github.com/user-attachments/assets/e670408a-aa15-41ae-aba7-8156bef969e2" />

### 5. Pick a template

There are two site types:

| Type | Used for |
|---|---|
| **Team site** | A shared workspace where members work on content together. Connected to a Microsoft 365 group |
| **Communication site** | Sharing information with a large audience, where most people only read |

I picked **Team site → Standard team**.

### 6. Preview and use the template

The Standard team template comes with one home page that shows team activity, news, and highlighted content. You can change the template later under Settings. Click **Use template**.

<img width="1209" height="833" alt="6" src="https://github.com/user-attachments/assets/d9d9c235-7532-4233-aaaf-7fb25f6311d8" />

### 7. Fill out the site info

<img width="1292" height="995" alt="7" src="https://github.com/user-attachments/assets/3056129c-14b9-4cc2-8572-b08f24f03415" />

| Field | What I entered |
|---|---|
| Site name | SharePoint Practice Lab - Daysean |
| Site description | Personal practice site for learning SharePoint admin: permissions, sharing, libraries, lists, recovery etc. |
| Group email address | SharePointPracticeLab-Daysean |
| Site address | `https://<tenant>.sharepoint.com/sites/SharePointPracticeLab-Daysean` |
| Privacy | Private - only members can access this site |
| Language | English |
