# 04 - Create and Publish a News Post

## Goal

Create and publish a news post on my site. I used it to post a quick guide for people on how to upload files and folders to SharePoint, based on what I did in [**03 - Create and upload Files and Folders**](03-create-and-upload-files-and-folder.md).

## Environment

- Microsoft 365 through my school account
- Site: SharePoint Practice Lab (team site from [**01 - Create a Team Site**](01-create-team-site.md))

---

### 8. Write the post

I wrote out the steps for uploading a file or folder, plus these sections:

| Section | What it says |
|---|---|
| **Permissions & Access** | You need edit permissions to upload. If you only have Read access or get "Access Denied," request access from the site owner |
| **Quick Reminders** | Don't use special characters (`/ \ ? * : < > \|`) in file names, since they cause sync errors in the OneDrive app |
| **Support** | Email the help desk with a screenshot if something breaks |

### 9. Name the post

When I clicked **Publish news**, SharePoint said **"Add a page title to continue."** The page title is separate from the heading on the page, and it's used in the page's URL. Click **Close**, then click the page name at the top left and fill in **Name**.
