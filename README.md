# Microsoft 365 Administration

A Microsoft 365 admin project covering SharePoint, Teams, OneDrive and more. Each part shows what I set up, how I did it, and what I learned.

I'm doing this to build hands-on Microsoft 365 skills for my IT internship and for roles in systems administration.

## Environment

- **Tenant:** Microsoft 365 through my school account
- **Limits:** I don't have admin rights on the tenant, so some features (like the SharePoint and Microsoft 365 admin centers) aren't available. Where that matters, I note it in that section.
- **Privacy:** Tenant names, emails and URLs are blurred or replaced with `<tenant>` in screenshots and notes.
